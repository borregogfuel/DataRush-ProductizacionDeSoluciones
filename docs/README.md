# NYC Taxi Safety Dashboard

A comprehensive web application for analyzing taxi safety patterns in New York City using machine learning and real-time data.

## 🌐 Live Demo

**Access the application:** [https://borregogfuel.github.io/DataRush-ProductizacionDeSoluciones/](https://borregogfuel.github.io/DataRush-ProductizacionDeSoluciones/)

## 🚀 Features

- **Interactive Map**: Explore NYC taxi zones with safety indicators
- **ML Predictions**: Get safety predictions and fare estimates using machine learning
- **Real-time Weather**: Current weather conditions for better trip planning
- **Safety Analytics**: Hourly safety patterns and zone-specific insights
- **Search Functionality**: Find specific locations and get safety recommendations

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript, Leaflet Maps
- **Backend**: Python Flask API
- **Machine Learning**: Rule-based deterministic system
- **Data Sources**: NYC Taxi & Limousine Commission data
- **Weather API**: OpenWeatherMap integration

## 📊 Data Sources

- NYC Taxi Trip Data (2023)
- NYPD Complaint Data
- Real-time weather data
- Zone and borough information

## 🔧 API Endpoints

- **Backend API**: `http://13.221.81.218:5000`
- **ML API**: `http://13.221.81.218:5002`

## 📱 Usage

1. Open the application in your browser
2. Use the search bar to find locations
3. Click on zones to see safety information
4. View ML predictions for fare estimates and safety scores
5. Check weather conditions for trip planning
